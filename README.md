# 環球大富翁

和朋友在線玩的大富翁。

打開 https://rancell.github.io/globe-monopoly/ ，點「開房間」，再把房間連結傳給朋友。朋友打開連結就能入座，不用註冊，也不用登入。

- 32 格世界城市棋盤，2 到 6 位玩家，人不夠可以加電腦玩家
- 買地、加蓋到摩天樓，同區城市越多過路費越貴
- 卡片屋用點數買卡：遙控骰子、路障、地雷、均富卡、查稅卡、購地卡、天使卡等 20 種
- 土地公廟擲筊請神明：財神、福神、土地公，也可能招來衰神、窮神
- 股市每天漲跌、銀行存款生利息、新聞事件
- 8 位原創角色，各有一個小技能
- 也可以點「本機遊戲」，在一台裝置上和電腦玩家或身邊的人輪流玩

連線訊息透過公共 MQTT 伺服器轉送（broker.emqx.io，備用 broker.hivemq.com）。拿到房間連結的人都能進入房間。

第三方程式碼：MQTT.js 5.14.1，MIT 授權，見 LICENSE-mqtt.md。
