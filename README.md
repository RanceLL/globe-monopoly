# 环球大富翁

和朋友在线玩的世界城市大富翁。

打开 https://rancell.github.io/globe-monopoly/ ，点「创建房间」，再把房间链接发给朋友。朋友打开链接就能入座，不用注册，也不用登录。

- 32 格世界城市棋盘，2 到 6 位玩家，人不够可以加电脑玩家
- 盖房、抵押、收购同色城市、旅行基金奖池
- 也可以点「单机试玩」，在一台设备上和电脑玩家或身边的人轮流玩

联机消息通过公共 MQTT 服务器转发（broker.emqx.io，备用 broker.hivemq.com）。拿到房间链接的人都能进入房间。

第三方代码：MQTT.js 5.14.1，MIT 许可，见 LICENSE-mqtt.md。
